# Subtitle Reader

Приложение для Android: показывает английские субтитры рядом с видео (в режиме разделённого экрана) и помогает учить слова. Работает полностью без интернета.

**[Скачать SubtitleReader.apk (последняя версия)](../../releases/latest/download/SubtitleReader.apk)**

Все версии — во вкладке [Releases](../../releases).

## Как установить

1. Откройте ссылку выше на телефоне и скачайте `SubtitleReader.apk`.
2. Откройте скачанный файл. Если Android спросит, разрешите установку из этого источника (браузера или «Файлов»).
3. Если появится предупреждение Google Play Protect «Приложение не проверено», нажмите «Всё равно установить»: приложение собрано здесь, из этого репозитория, и не публиковалось в Google Play.

Новая версия ставится поверх старой: загруженные серии, слова и позиции сохраняются.

## Как пользоваться

- **Aa → Add subtitle files** — добавить субтитры (.srt, .ass, .vtt, .csv), можно сразу несколько. Они остаются в приложении.
- **▶** — текст плавно едет по времени субтитров. Реплика на линии чтения звучит сейчас, справа стрелка с временем.
- **Потянуть текст пальцем** — подогнать под видео: движение продолжится с той строки, что на линии.
- **Касание пустого места** — пауза / продолжить. Панель кнопок прячется во время движения и возвращается на паузе.
- **⟲2 / ⟳2** — на 2 секунды назад / вперёд.
- **Касание слова** — отметить. Соседние отмеченные слова склеиваются во фразу. Повторное касание снимает отметку.
- **Долгое нажатие на слово** — скопировать слово или строку, открыть Cambridge Dictionary, Reverso Context или YouGlish.
- **Значок закладки** — список ваших слов: копирование для Quizlet / Anki, удаление.
- **Aa** — список серий, имена говорящих, размер текста, цвета персонажей.

## CSV-формат

Три колонки: время, говорящий, текст. Разделитель — запятая или точка с запятой.

```
time,speaker,text
1:41,Loid,This won't do.
1:42,Franky,What?!
```

## Как это собирается

Весь проект лежит в `app.zip`. При каждом изменении в репозитории GitHub Actions (`.github/workflows/build-apk.yml`) распаковывает архив, создаёт Android-проект с помощью Capacitor 6 из папки `www`, собирает APK и публикует его в Releases. Подпись — постоянный ключ из `ci/debug.keystore`, поэтому обновления устанавливаются поверх. Чтобы обновить приложение, загрузите новый `app.zip` поверх старого.
